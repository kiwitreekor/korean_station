# Korean Station Set
  
**Korean Station Set** is a NewGRF that adds several korean style station pieces into OpenTTD.  
You can download this via Online content in-game, or [Github release page](https://github.com/kiwitreekor/korean_station/releases).  
  
## How to build
To build the project, follow these steps:

1. **Install the Latest Nightly Version of nml**  
   Download and install the latest nightly version of nml from the official repository(https://github.com/OpenTTD/nml).

2. **Ensure Python 3.7 or Higher is Installed**  
   Verify that Python 3.7 or a newer version is installed on your system. You can check your Python version by running:
   ```bash
   python --version
   ```

3. **Install the Required Jinja2 Library**  
   Use `pip` to install the Jinja2 library. Run the following command:
   ```bash
   pip install jinja2
   ```

4. **Run `build.bat` to Start the Build Process**  
   Execute the `build.bat` script to build the project. Open a terminal or command prompt, navigate to the project directory, and run:
   ```bash
   build.bat
   ```
